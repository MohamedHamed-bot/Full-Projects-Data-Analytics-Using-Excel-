## Project 1 

# 📊 Revenue Growth Analysis Dashboard - Geidea
An interactive data analysis project designed to track and optimize sales performance, profitability, and operational efficiency for **Geidea**.

## 🎯 Project Objective
The primary goal of this analysis is to transform raw sales data into **Actionable Insights**, enabling the commercial team to monitor **Revenue Growth**, evaluate **Sales Rep Performance**, and identify regional trends.

---

## 🛠️ Tech Stack & Methodology
* **Excel (Advanced):** Data cleaning, complex formulas, and Pivot Tables.
* **Data Modeling:** Structuring data to calculate Net Profit and Achievement percentages.
* **Visualization:** Creating an interactive dashboard with dynamic slicers for Regions (Alex, Cairo, Giza).

### 🔍 Key Analysis Steps (Pivot Tables):
* **Return Analysis:** Created pivot tables to count total returned quantities based on **simplified return reasons**.
* **Geographical Insights:** Counted returned quantities based on **City** and **Town** to identify logistics bottlenecks.
* **Performance Tracking:** Evaluated Sales Reps based on Net Profit and target achievement.

---

## 📈 Executive Summary (Key Findings)
Based on the dashboard analysis:
* **Total Revenue:** 31.29M EGP.
* **Total Achievement:** **112.43%** (Exceeding the set targets).
* **Net Profit:** 5.47M EGP with a **3.36% Total Growth**.
* **Operational Reach:** 27 Active States (90% of total coverage).
* **Top Category:** **Retail** leads the revenue with 13.44M EGP.

# 💰 Personal Finance Tracker - Freelance Project
A comprehensive financial management dashboard designed to track **Net Worth**, **Income Streams**, and **Expense Categorization** with high visual precision.

## 🎯 Project Overview
This project was developed for a client to provide a bird's-eye view of their financial health. It transforms daily transactions into actionable insights through interactive visualizations.

## 🛠️ Tech Stack
* **Excel / Power BI:** Data modeling and dashboard architecture.
* **Advanced Pivot Tables:** Used for multi-dimensional analysis (Spending by category, Income by source).
* **Data Visualization:** Custom UI design featuring dynamic cards and progress bars.

---

## 🔍 Key Analytical Features
As shown in the analysis structure:
* **Expense Breakdown:** Categorized spending into Housing (44%), Personal (28%), and Transportation (28%) to monitor outflow.
* **Income Goal Tracking:** A dynamic progress bar showing a **99% achievement rate** towards the monthly target.
* **Asset Monitoring:** Real-time tracking of Stocks ($22,500) and Real Estate ($15,700).
* **Net Worth Calculation:** Aggregated total net worth reaching **$277,802**.

---

## 📊 Methodology (Pivot Tables Logic)
The backend of this dashboard relies on structured pivot tables:
1. **Return/Reason Analysis:** (Implemented for logistical data) to count returned quantities by city and town.
2. **Time-Series Analysis:** Monthly filtering (Jan 2023) to compare spendings vs. income trends.
